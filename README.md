# PLUTONF

Aplicación de gestión espacial desarrollada en JavaFX y MySQL.

## Autor
Manuel Ponferrada

## Tecnologías utilizadas
- Java
- JavaFX
- Maven
- MySQL / MariaDB
- JDBC

## Estructura del proyecto
El proyecto sigue el patrón MVC:
- Model
- DAO
- Controllers
- Vistas FXML

## Funcionalidades
- Gestión de naves
- Gestión de módulos
- Gestión de astronautas
- Gestión de misiones
- Gestión de mantenimientos
- Gestión de intervenciones
- Consultas relacionales
- Acoplamiento de módulos

## Cómo ejecutar
1. Clonar el repositorio
2. Configurar la base de datos
3. Ejecutar el script SQL
4. Abrir el proyecto con Maven
5. Ejecutar PlutonfApplication

## Base de datos
La conexión se configura mediante XML.

## Programación orientada a objetos
El proyecto utiliza:
- Herencia
- Interfaces
- Clases abstractas
- Sobreescritura
- Sobrecarga
- Colecciones
